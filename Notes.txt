Из-за недоступности API hh.ru в проекте используется предоставленный резервный файл hh_vacancies.json.
Он содержит 5 уникальных компаний, поэтому анализ выполняется по всем компаниям из файла без добавления дубликатов.
Ограничение связано с составом учебных данных. Использование пяти компаний согласовано с ментором.
